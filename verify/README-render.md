# 화면 렌더 검사 — `verify/render-check.mjs`

## 왜 있나

**2026-10-12: 분석 리포트 화면이 통째로 비어 있는 것을 사용자가 먼저 발견했다.**
그 시점에 테스트 **1022개가 전부 초록**이었고 `npm run build` 도 통과했다.

Vue 는 **렌더 중 예외가 나면 그 서브트리를 조용히 버린다.** 그래서 증상은
*"화면 일부가 안 보인다"* 뿐이고, API 는 200 이며 로그에도 안 남는다.
단위 테스트는 **브라우저에서 그려지는가**를 원리상 못 본다.

같은 회차에 이 하니스가 **배포본에서 결함 셋**을 찾았다:

| 화면 | 증상 | 원인 |
|---|---|---|
| 분석 리포트 | **전부 안 보임**(0자) | `TREND_KO` 선언 없음 |
| 설정 | 749자만 보임 | `loadStatus()` — 이름 바꾸고 호출부만 남음 |
| 전략 연구소 | 일부 사라짐 | `{ name: 'backtest' }` 에 `:id` 누락 |

## 쓰는 법

```bash
# ① 터널 — **nginx(80)** 로 열어야 한다. 앱 포트(50000) 직결은 자산 경로가 안 맞아
#    JS 가 아예 안 돌고, 그러면 **정상 화면도 0자**로 나온다(자가 거짓말한다).
ssh -i ~/.ssh/haru_homelab_ed25519 -f -N -L 18099:127.0.0.1:80 homelab25

# ② 검사 — 종료코드 0=통과 · 1=렌더 실패 · 2=측정 불가
node verify/render-check.mjs
#   로컬 dev 서버를 볼 때: node verify/render-check.mjs http://127.0.0.1:5173
```

## ⚠️ 막다른 길 셋 — 다시 시도하지 말 것

1. **시스템 Chrome 헤드리스** → 이 맥에서 `CVDisplayLinkCreateWithCGDisplay failed` 로 죽는다
2. **LAN 주소(`192.168.11.25`)로 Chromium** → macOS 로컬 네트워크 권한 때문에
   `ERR_ADDRESS_UNREACHABLE`. **터널로 `127.0.0.1`** 에 붙는 이유가 이것이다
3. 🔴 **`--virtual-time-budget` + `--screenshot`/`--dump-dom`** → ES 모듈 로드 전에 찍는다.
   **정상 화면도 똑같이 흰 PNG(7,279바이트)** 가 나왔다. 이걸 결과로 믿었으면
   *"포트폴리오도 비었다"* 는 **틀린 보고**를 했을 것이다.
   ★ 갈라 준 것은 **정상이라고 아는 화면과의 대조**였다 — 자를 먼저 의심하는 그 절차.

## 판정 규칙

- `main` 의 보이는 텍스트가 **100자 미만이면 실패**(0 은 완전 실패)
- **콘솔 에러·미처리 예외가 하나라도 있으면 실패** — Vue 렌더 오류는 여기로만 드러난다
- 화면마다 **사용자가 읽는 문구**가 있는지 확인(클래스명·식별자로 보면 minify 에 사라진다)
- 세로 스크롤 유무를 함께 출력한다(*"한 화면에 담아라"* 요구의 측정값)
